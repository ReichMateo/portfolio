# Portfolio — Mateo Reich

Portfolio personal de Mateo Reich, desarrollador web full stack.

## Tecnologías

- HTML, CSS y JavaScript
- React y TypeScript
- Node.js, Express y PostgreSQL
- Go

## Ejecutar localmente

Abrí `index.html` directamente en el navegador.

También puedes iniciar un servidor local:

```bash
python -m http.server 8000
```

Luego visitá `http://localhost:8000`.

## Archivos

- `index.html`: sitio y configuración del contenido.
- `CV_Mateo_Reich.pdf`: currículum descargable.
- `vercel.json`: configuración para despliegue en Vercel.
